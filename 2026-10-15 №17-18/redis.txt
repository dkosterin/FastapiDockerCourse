Redis это нереляционная система управления базами данных (NoSQL)
В отличие от SQL баз данных Redis хранит данные
не в постоянной памяти, а в оперативной.
Данные хранятся не в таблицах, а в виде словаря
Ключ: значение

Может использоваться как кэш (хранить сессии или другие данные,
которые взяли из БД), как очередь задач, как брокер сообщений и т.д.

Установка
docker run --name MyRedis -d -p 6379:6379 redis
Redis-cli
docker exec -it MyRedis redis-cli

Основные команды:
SET -- установить значение по ключу
GET -- получает значение по ключу
DEL -- удаление значения по ключу
EXISTS -- имеется ли такой ключ
RENAME -- меняет название ключа
KEYS * -- список всех ключей
FLUSHDB -- очистить все
INCR -- увеличить на 1
DECR -- уменьшить на 1
INCRBY -- увеличить на какое-то значение
DECRBY -- уменьшить на какое-то значение

Часто ключи имеют вид "user:153"
Пространства имен "user:{id}"
users:153:name, users:153:settings
KEYS user:* получить все ключи, которые начинаются на user:

Ключи можно делать временными
TTL (time to live) время жизни
SET key value EX seconds
EXPIRE key seconds -- установить TTL для существующего ключа
TTL key -- сколько осталось времени для ключа
PERSIST key -- сбросить TTL

Типы данных:
Строки -- текстовые данные

Списки -- упорядоченный набор элементов
LPUSH -- добавление в начало списка 
RPUSH -- добавление в конец
LRANGE key start end -- список элементов в диапазоне
LRANGE key 0 -1
LLEN -- длина списка
LINDEX -- элемент по индексу
LPOP -- удалить первый
RPOP -- удалить последний

Множества -- неупорядоченный набор уникальных элементов
SADD -- добавить элемент в множество
SMEMBERS -- множество по ключу
SREM -- удалить элемент из множества по значению

Упорядоченное множество -- упорядоченный набор (отсортирован)
ZADD key score member -- добавить элемент
ZRANGE key start stop -- получить элементы
ZRANGE key start stop WITHSCORES

Хэш-таблицы -- ключ: значение
HSET key field value -- задать значение
HGET key field 
HGETALL key -- вывести всю хэш таблицу
HDEL key field -- удалить поле
